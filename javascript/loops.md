# Циклы в JavaScript

Циклы позволяют выполнять один и тот же блок кода многократно. Каждое такое повторение называется **итерацией**.

## 1. Цикл for

Используется, когда мы **заранее знаем**, сколько раз нужно повторить действие.

**Синтаксис:**

```javascript
for (начало; условие; шаг) {
  // тело цикла
}
```

Пример:

```javascript
for (let i = 0; i < 5; i++) {
  console.log("Итерация номер " + i); // Выведет числа от 0 до 4
}
```
- **Начало:** let i = 0 — выполняется один раз перед стартом.

- **Условие:** i < 5 — проверяется перед каждой итерацией. Если false, цикл останавливается.

- **Шаг:** i++ — выполняется после каждой итерации.

## 2. Цикл while

Используется, когда мы не знаем заранее, сколько раз нужно повторить код. Цикл работает, пока условие истинно (true).

```javascript
let i = 0;
while (i < 5) {
  console.log(i);
  i++; // ВАЖНО: не забываем менять переменную!
}
```

## 3. Цикл do...while

Похож на while, но с одним отличием: он гарантированно выполнится хотя бы один раз, даже если условие изначально ложно (false). Проверка условия идет после выполнения тела.

```javascript
let i = 10;
do {
  console.log("Это выведется, хотя 10 не меньше 5");
  i++;
} while (i < 5);
```

## 4. Управление циклом: break и continue

Иногда нужно прервать цикл досрочно или пропустить одну итерацию.

- **break** — полностью прерывает цикл.

- **continue** — пропускает текущую итерацию и переходит к следующей.

```javascript
for (let i = 0; i < 10; i++) {
  if (i === 3) continue; // Пропустит число 3
  if (i === 7) break;    // Полностью остановит цикл на числе 7
  console.log(i);        // Выведет: 0, 1, 2, 4, 5, 6
}
```

## 5. Цикл for...in

Используется для перебора **свойств объекта** (ключей). Он проходит по всем перечисляемым свойствам.

**Пример с объектом:**

```javascript
let user = {
  name: "Иван",
  age: 25,
  city: "Москва"
};

for (let key in user) {
  console.log(key + ": " + user[key]);
  // Выведет: name: Иван, age: 25, city: Москва
}
```

## 6. Цикл for...of
Используется для перебора итерируемых объектов (массивов, строк). Он проходит по значениям, а не по ключам.

Пример с массивом:
```javascript
let fruits = ["Яблоко", "Банан", "Апельсин"];

for (let fruit of fruits) {
  console.log(fruit);
  // Выведет: Яблоко, Банан, Апельсин
}
```

- Переменная fruit получает сам элемент (значение).

- Это самый современный и удобный способ перебора массивов.

- В отличие от forEach, здесь можно использовать break и continue.
