# Условия в JavaScript

Условия позволяют выполнять разный код в зависимости от того, истинно (true) или ложно (false) выражение.

## 0. Операторы сравнения

Операторы сравнения всегда возвращают логическое значение: `true` или `false`.

- `>` — больше
- `<` — меньше
- `>=` — больше или равно
- `<=` — меньше или равно
- `==` — нестрогое равенство (сравнивает только значения, *не рекомендуется к использованию*)
- `===` — строгое равенство (сравнивает и значение, и тип данных — **используйте всегда его**)
- `!=` — нестрогое неравенство
- `!==` — строгое неравенство

```javascript
console.log(5 > 3); // true
console.log(5 === "5"); // false (разные типы данных)
console.log(5 == "5");  // true (оператор == приводит типы, поэтому так лучше не делать)
```

## 1. Оператор if
Базовый синтаксис:

```javascript
if (условие) {
  // код, который выполнится, если условие true
}
```

Пример:
```javascript
let age = 18;
if (age >= 18) {
  console.log("Доступ разрешен");
}
```

## 2. Оператор if...else
Если нужно выполнить код и в случае, когда условие ложно:

```javascript
if (условие) {
  // если true
} else {
  // если false
}
```

## 3. Оператор else if
Для проверки нескольких условий по цепочке:

```javascript
if (x > 0) {
  console.log("Положительное");
} else if (x < 0) {
  console.log("Отрицательное");
} else {
  console.log("Ноль");
}
```

## 4. Тернарный оператор (? :)
Короткая запись if...else в одну строку:

```javascript
let result = (age >= 18) ? "Взрослый" : "Ребенок";
```

### Цепочка тернарных операторов

Тернарные операторы можно вкладывать друг в друга, чтобы проверить несколько условий подряд (аналог `else if`). 

```javascript
let age = 18;
let message = (age < 3) ? 'Здравствуй, малыш!' :
              (age < 18) ? 'Привет!' :
              (age < 100) ? 'Здравствуйте!' :
              'Какой необычный возраст!';

console.log(message);

## 5. Оператор switch
Удобен, когда нужно сравнить одно значение с множеством вариантов:

```javascript
switch (day) {
  case 1:
    console.log("Понедельник");
    break; // обязательно, иначе код "провалится" дальше
  case 2:
    console.log("Вторник");
    break;
  default:
    console.log("Другой день");
}
```

## 6. Преобразование типов:

**Falsy (ложные значения):**
- К ним относятся: 0, пустая строка "", null, undefined, NaN и false. Из-за этого их называют «ложными».

``` javascript
if (0) {
  // 0 — это falsy (ложь), поэтому этот код никогда не выполнится
  console.log("Это не выведется");
}
```

**Truthy (правдивые значения):**
- Все остальные значения становятся true, поэтому их называют «правдивыми».
> Важно помнить: пустой массив [] и пустой объект {} — это тоже true.
